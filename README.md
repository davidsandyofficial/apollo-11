# Apollo 11: Eight Days to the Moon

A cinematic, scroll-driven single-page story of the Apollo 11 mission (July 16 to 24, 1969). Plain HTML, CSS and JavaScript, no build step.

Open `index.html` locally, or host the folder with GitHub Pages (Settings > Pages > Deploy from branch `main`, folder `/`).

Facts are drawn from NASA's Apollo 11 mission records. Follow [@davidsandy on X](https://x.com/davidsandy) for more.
